# Merkavania: Asset Pipeline

Art and audio are generated by AI services connected to Claude Code as MCP servers:
- **PixelLab**: pixel-art sprites, animations, top-down tilesets, map objects.
- **ElevenLabs**: sound effects and music.

## MCP setup (one-time, run by the user)
> Check these commands against the vendors' current docs before running them; endpoints and package names can change. Keep API keys in environment variables, never in the repo.

```bash
# PixelLab: remote HTTP MCP server, token from your pixellab.ai account
claude mcp add pixellab --transport http https://api.pixellab.ai/mcp \
  --header "Authorization: Bearer $PIXELLAB_API_TOKEN"

# ElevenLabs: official MCP server (requires uv / uvx)
claude mcp add elevenlabs -e ELEVENLABS_API_KEY=$ELEVENLABS_API_KEY \
  -e ELEVENLABS_MCP_BASE_PATH=./assets-src/audio/raw -- uvx elevenlabs-mcp
```
Run `claude mcp list` to verify the servers. Add `-s project` to share the config via `.mcp.json`, and reference the keys as env vars.

## Directory flow
```
assets-src/                      # raw generations & sources, committed, NOT shipped
  pixellab/<category>/<name>/    # raw PixelLab outputs + prompt.txt with exact prompt/params
  audio/raw/                     # raw ElevenLabs outputs + prompts.md
public/assets/                   # game-ready, shipped
  sprites/<category>/<name>.png (+ .json for multi-frame)
  tiles/<biome>/<tileset>.png
  sfx/<name>.ogg + .mp3
  music/<biome>.ogg + .mp3
src/data/assetManifest.ts        # the ONLY place paths appear; code uses keys
```
**Always save the prompt and parameters next to each raw generation** so the asset can be regenerated or restyled consistently.

## Art conventions
- **View:** strict top-down 90°. **16px** tile grid, 480×270 internal resolution.
- **Sizes:** Merkava tank hull about 32×32 with the turret as a separate sprite (barrel included, about 32×12 depending on Mk). Scout 8–12px. Enemy vehicles 24–40px. Bosses up to 96px+.
- **Orientation:** sprites face **east** (0 rad) and are rotated in the engine. Hull and turret are separate sprites, and the turret pivot is marked in the manifest (`origin`).
- **Animation:** tread strips (2–4 frames), a muzzle flash as its own sprite, explosions as 6–10 frame strips.
- **Per-Mk sets:** `mk2_hull`, `mk2_turret`, `mk3_hull`, …. They must be recognisably Merkava: front-mounted engine, a long flat wedge turret set toward the rear, rear hatch. Mk3/Mk4 get their distinctive turret shapes (Mk4's more angular modular turret with Trophy panels).
- **Lighting:** light from the top-left, 1px dark outline on units, no outline on terrain.
- **Palette:** a limited palette per biome (desert: sand, ochre, khaki, olive drab, dusty grey). Keep the player tank the same olive/sand IDF colours in every biome for readability. Store palettes as `.hex` in `assets-src/palettes/` and pass them to PixelLab when it supports palettes.
- **Tilesets:** generate the top-down terrain transitions (sand↔rock, sand↔road, ground↔water, cliff edges per elevation) as Wang/autotile sets. Import them into Tiled as `.tsj` with terrain sets configured.
- **Gate readability:** each gate terrain or material gets a distinct, obvious look (see `LEVEL_DESIGN.md`).

### PixelLab prompt templates
- Tank hull: `top-down view, 90 degree overhead, pixel art Israeli Merkava Mk2 main battle tank hull without turret, facing right, olive sand color, 32x32, transparent background`
- Turret: `top-down overhead pixel art Merkava Mk2 turret with 105mm gun barrel, facing right, wedge shaped, transparent background`
- Enemy: `top-down overhead pixel art <enemy description>, facing right, military, <size>, transparent background`
- Tileset: `top-down desert sand to cracked rock transition tileset, 16x16, pixel art`
- Adjust these per the PixelLab MCP tool parameters (size, view, outline, shading, palette) and always record the final values.

## Post-processing
- Check sizes and trim transparent padding consistently (the pivot must stay correct).
- Multi-frame sprites become a uniform-grid spritesheet plus a frame config in the manifest. Once the sprite count grows, add an atlas packer script under `scripts/`.
- Audio: convert raw output to `.ogg` and `.mp3` (ffmpeg) and normalise loudness: SFX about -16 LUFS short-term peak, music about -18 LUFS integrated. Trim silence and make music loops seamless.

## Placeholders
Until an asset exists, `Preload` generates a placeholder texture in code (coloured shapes with a direction marker) under the same manifest key. Each manifest entry has `status: 'placeholder' | 'generated' | 'final'`, so missing art is easy to list.
